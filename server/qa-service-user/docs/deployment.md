# QA Service User 部署文档

## 概述

本文档描述 QA Service User 服务的部署架构和配置。该服务作为医疗问答系统的用户管理模块，与 MySQL 数据库和 phpMyAdmin 管理工具协同工作。

## 部署架构图

###  部署拓扑

#### Docker容器部署架构
```
┌──────────────────────────────────────────────────────────┐
│                    Docker Host                            │
│                                                           │
│  ┌────────────────────────────────────────────────────┐  │
│  │         healthcare_network (bridge网络)            │  │
│  │                                                     │  │
│  │  ┌──────────────┐      ┌──────────────┐           │  │
│  │  │ MySQL 8.4    │      │ phpMyAdmin   │           │  │
│  │  │ Port: 3306   │←────→│ Port: 80     │           │  │
│  │  │ (映射3301)   │      │ (映射8001)   │           │  │
```
